# Templates de Prompt (operacionais)

> Regra de ouro: **1 plano = 1 ação.** Planos com múltiplas ações quebram.

## Keyframe de cena (imagem)

```
[Master Style Prompt]
[Prompt canônico do(s) personagem(ns) OU Soul ID treinado]
Scene: {ação única da cena}.
Location: {cenário-base anexado como referência de imagem}.
Framing: {wide shot / medium shot / close-up}.
Time: enchanted night.
Scene emotion: {emoção}.
```

## Animação (image-to-video sobre keyframe aprovado)

```
{ação simples e única — ex: "the boy runs downhill, his frevo umbrella
opens and he glides for two meters"}.
Camera: {static / slow lateral tracking / gentle push-in}.
No cuts. No text. Natural loop if possible. Duration: {5–10}s.
```

## Cenário-base (uma vez por locação, 3–4 ângulos fixos)

```
[Master Style Prompt]
Location: {descrição da locação encantada — ver Bíblia, seção 7}.
Empty scene, no characters.
Angle {A/B/C}: {descrição do ângulo — ex: "looking uphill from street
level, church silhouette at the top"}.
Time: enchanted night.
```

## Checklist antes de gerar qualquer asset

1. O prompt inclui o Master Style Prompt? (Trava 1)
2. O personagem está via Soul ID/referência de imagem, não só texto? (Trava 2)
3. A locação usa o cenário-base como referência? (Trava 3)
4. O nome do arquivo segue a convenção e a versão? (Trava 4)
5. É o modelo travado da temporada? (Trava 5)
