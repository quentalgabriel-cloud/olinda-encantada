## Como usar

1. **Nada aqui é canônico até ser promovido para a Bíblia** (Doc 01) e registrado no changelog dela. A v1.2 da Bíblia já incorporou os achados verificados de maior valor.
2. **Itens ⚠️** são pistas de pesquisa de campo, não fatos — não usar em material publicado sem confirmar.
3. **Diretrizes culturais/éticas** (Doc 01, seção 9): elementos de religiosidade afro-brasileira (maracatu-nação, coco da Xambá) e representação indígena (Iangai/Marim) só entram em cena após consulta comunitária.
4. **Próximo passo que nenhum relatório alcança:** a Lacuna 6 (infância olindense) depende da conversa de escuta — kit pronto em `producao/parcerias/kit-conversa-thales.md`.
